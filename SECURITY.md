# Security Policy

## Reporting a vulnerability

Please report security issues privately to Talha Amjad.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/voxgig-sdk/baserow-sdk/issues

## Scope

This policy applies to the generated Talha Amjad SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Baserow API spec public API, generated by
Talha Amjad. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
